# AGENTS.md

BridgeNode MCP wrapper (`@bridgenode/mcp`). stdio MCP server proxying to remote streamable-HTTP endpoint with automatic x402 payment on Solana USDC. No API keys.

## Commands

- `npm install` — install deps
- `npm run build` — build (tsup → dist/: index.js ESM + index.cjs CJS + .d.ts)
- `npm test` — run tests (node --test with tsx)
- `npm run test:e2e` — e2e real-payment test (requires TEST_WALLET_PK — do NOT run without explicit approval)
- `npm run typecheck` — TypeScript check (tsc --noEmit)

## Structure

- `src/` — source (entry: `src/index.ts`)
- `tests/` — tests
- `dist/` — build output (GENERATED — never edit by hand)
- `skills/bridgenode/SKILL.md` — agent skill (agentskills.io format)

## Conventions

- TypeScript strict; ESM-first (package `type: module`), dual build emits CJS too
- MCP server entry uses stdio transport; remote URL from env (`BRIDGENODE_BASE_URL`)
- Keep public exports in `src/index.ts`

## Rules

- ✅ Always: `npm run build` + `npm test` + `npm run typecheck` before committing
- ✅ Add tests in `tests/` for new behavior
- 🚫 Never: commit `.env` or any secrets (wallet keys!)
- 🚫 Never: edit `dist/` (regenerated by build)
- 🚫 Never: run `test:e2e` without explicit approval (spends real USDC)
- 🚫 Never: modify `package-lock.json` by hand — use `npm install`
